# Contributing

The Nouscrates repository is intended to become a permanent historical record,
not an evolving collaborative project.

The canonical text of the Nouscrates Oath is contained in `OATH.md`.

Once the initial version of this repository is finalized and made public:

- No changes to the canonical oath will be accepted.
- No pull requests will be accepted.
- No new features, revisions, or expansions are planned.
- Issues and discussions may be disabled.
- The original repository should be regarded as frozen.

Anyone is free to fork, copy, translate, modify, criticize, extend, or build
upon Nouscrates.

Modified versions are encouraged to use a distinct name or otherwise state
clearly that they are derivatives. They should not be represented as the
canonical Nouscrates Oath.

No permission is required.
